# 🩺 Wound Monitoring AI

An AI-powered web application that analyzes wound images and tracks healing progress over time, with doctor-patient interaction.

---

## 🚀 Features

* 📸 Upload wound images for analysis
* 🤖 AI-based healing score prediction
* 📊 Daily/weekly healing progress graph
* 👨‍⚕️ Doctor dashboard for patient monitoring
* 📝 Doctor notes and recommendations
* 🔐 Secure authentication (patient & doctor roles)

---

## 🛠 Tech Stack

* **Frontend:** React (Vite, Tailwind CSS)
* **Backend:** FastAPI (Python)
* **Machine Learning:** PyTorch
* **Database:** SQLite

---

## 📂 Project Structure

backend/ → FastAPI server + ML model
frontend/ → React UI

---

## ▶️ Run Locally

### 🔹 Backend

cd backend
venv\Scripts\activate
uvicorn main:app --port 8001

### 🔹 Frontend

cd frontend
npm install
npm run dev
